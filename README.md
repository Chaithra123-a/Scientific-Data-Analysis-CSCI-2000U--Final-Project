# Scientific Data Analysis (CSCI 2000U) - Final Project

## Project Overview

This project involves a complete data science workflow, from data acquisition and cleaning to exploratory analysis and modeling. The objective is to investigate a specific research question using a real-world dataset while adhering to scientific data analysis constraints.

## Data Science Workflow

Following the process outlined by O'Neil & Schutt (2014), this project covers:

1. **Locating & Importing Data:** Sourcing a dataset from public repositories.


2. **Data Processing:** Cleaning and preparing raw data for analysis.

3. **Exploratory Data Analysis (EDA):** Identifying patterns and distributions.

4. **Modeling:** Applying descriptive statistics or basic regression/clustering.

5. **Communication:** Reporting findings through visualizations and written interpretation.

## Assignment Requirements

## Notebook Structure

The Jupyter Notebook is organized into the following sections:

1. **Title:** Project title, name, and student ID.


2. **Introduction:** Background on the chosen question and data source (150–500 words).


3. **Analyses:** Python code for data loading, cleaning, and manipulation.


4. **Discussion:** Summary and interpretation of numerical results and graphs.


5. **GenAI Disclosure:** Detailed account of any AI tools used, including prompts and verification steps.


6. **References:** Links to data sources and any external packages used.
